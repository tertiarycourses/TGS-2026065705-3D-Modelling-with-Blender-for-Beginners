# Lab 1: Navigate Blender and organise a production scene

**Level:** Foundation

**Alignment:** K2 · A1

## Scenario

You are onboarding to a small studio and must turn an unfamiliar Blender file into a controlled working scene.

## Objective

Navigate the interface, distinguish Object and Edit modes, organise objects and preserve a clean baseline.

## Output

A named, organised scene with a short evidence presentation.

## Files

- `INSTRUCTIONS.md` / `INSTRUCTIONS.pdf` — detailed learner procedure
- `CHECKLIST.md` / `CHECKLIST.pdf` — acceptance and evidence checks
- `STARTER.blend` — working input
- `EXAMPLE.blend` — reference output or reusable example
- `Example-Presentation.pptx` — polished evidence-story template
