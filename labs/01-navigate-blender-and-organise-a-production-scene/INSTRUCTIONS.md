# Instructions — Lab 1

## Before you begin

- Use Blender and work only on a copy of the starter file.
- The supplied sample files originate from Blender 2.91. Open a copy in current Blender and use Save As before editing.
- Preserve the original input and save incremental versions.
- Capture evidence at the points named below.

## Step-by-step

1. Copy STARTER.blend to a new versioned working file and open it.
2. Record the Blender version shown in Help > About Blender.
3. Identify the 3D Viewport, Outliner, Properties editor and Timeline.
4. Orbit, pan, zoom and frame the selected object.
5. Switch between perspective and orthographic views and capture both.
6. Select objects in the viewport and Outliner; confirm the active object.
7. Move, rotate and scale a copy on constrained axes.
8. Enter Edit Mode, select vertices, edges and faces, then return to Object Mode.
9. Create collections for Model, Cameras and Lights.
10. Rename objects with role-based names and remove unintended duplicates.
11. Save an incremental version and reopen it to confirm integrity.
12. Update the evidence presentation with screenshots, version and result.

## Expected result

A named, organised scene with a short evidence presentation.

## Evidence to include

- Interface screenshot
- Perspective and orthographic comparison
- Outliner hierarchy
- Transform panel
- Saved-version confirmation

## Troubleshooting

- If a command or tool behaves differently, record the Blender version and compare the current Blender manual.
- If a modifier or bevel looks inconsistent, verify object scale before changing geometry.
- If an export looks wrong, re-import it into a clean file and compare dimensions, normals, hierarchy and materials.
- Never overwrite the preserved starter or baseline while diagnosing.
