# Instructions — Lab 8

## Before you begin

- Use Blender and work only on a copy of the starter file.
- The supplied sample files originate from Blender 2.91. Open a copy in current Blender and use Save As before editing.
- Preserve the original input and save incremental versions.
- Capture evidence at the points named below.

## Step-by-step

1. Duplicate the latest approved file and freeze a baseline inventory.
2. Remove hidden geometry, accidental duplicates and unused materials only after review.
3. Confirm dimensions, units, origins, transforms and triangle count.
4. Retest the animation after geometry and data cleanup.
5. Set the final camera, render engine, samples, resolution and output path.
6. Render a neutral evidence image and the approved presentation image.
7. Place only intended export objects in a named collection.
8. Export GLB or FBX with documented axes, scale and animation settings.
9. Open a clean Blender file and import the exported asset.
10. Compare dimensions, hierarchy, materials, normals and animation with the source.
11. Create a manifest listing source, export, textures, previews, version and known limitations.
12. Package all dependencies and mark the release pass, conditional pass or fail.

## Expected result

A release package containing editable source, GLB/FBX export, preview and validation manifest.

## Evidence to include

- Before/after statistics
- Neutral and final renders
- Export settings
- Clean re-import checks
- Release manifest

## Troubleshooting

- If a command or tool behaves differently, record the Blender version and compare the current Blender manual.
- If a modifier or bevel looks inconsistent, verify object scale before changing geometry.
- If an export looks wrong, re-import it into a clean file and compare dimensions, normals, hierarchy and materials.
- Never overwrite the preserved starter or baseline while diagnosing.
