# Lab 8: Optimise, render and export the fish-bowl capstone

**Level:** Advanced

**Alignment:** K8–K9 · A7–A8

## Scenario

The approved animated fish must be packaged for a lightweight viewer and handed off with verification evidence.

## Objective

Optimise the full scene, render final evidence, export the intended asset and validate the package by round trip.

## Output

A release package containing editable source, GLB/FBX export, preview and validation manifest.

## Files

- `INSTRUCTIONS.md` / `INSTRUCTIONS.pdf` — detailed learner procedure
- `CHECKLIST.md` / `CHECKLIST.pdf` — acceptance and evidence checks
