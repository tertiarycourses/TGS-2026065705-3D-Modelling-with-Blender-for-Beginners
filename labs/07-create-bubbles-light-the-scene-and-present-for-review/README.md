# Lab 7: Create bubbles, light the scene and present for review

**Level:** Advanced

**Alignment:** K8 · A6–A7

## Scenario

Stakeholders need a short aquarium presentation that keeps the fish readable and demonstrates controlled secondary motion.

## Objective

Add a lightweight bubble/force effect, build purposeful lighting and present a review decision.

## Output

A review scene with bubbles, three-point lighting and a decision-ready presentation.
