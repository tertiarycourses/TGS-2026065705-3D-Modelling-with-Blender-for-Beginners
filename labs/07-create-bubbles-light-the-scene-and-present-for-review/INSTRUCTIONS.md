# Instructions — Lab 7

## Before you begin

- Use Blender and work only on a copy of the starter file.
- The supplied sample files originate from Blender 2.91. Open a copy in current Blender and use Save As before editing.
- Preserve the original input and save incremental versions.
- Capture evidence at the points named below.

## Step-by-step

1. Copy the starter and define the review camera and duration.
2. Create or inspect a bubble emitter and keep particle counts modest.
3. Set bubble lifetime, size variation and upward movement.
4. Add a force field only if it improves controlled variation.
5. Cache or bake the simulation when stable and record the range.
6. Add a key light that reveals the fish body form.
7. Add fill to retain shadow detail and a rim for separation.
8. Check the scene under a neutral diagnostic light.
9. Create a short viewport or Eevee preview.
10. Build a review slide with brief, wireframe, material and motion evidence.
11. State known limitations and the approval decision required.
12. Record stakeholder feedback and the next owner/action.

## Expected result

A review scene with bubbles, three-point lighting and a decision-ready presentation.

## Evidence to include

- Particle settings
- Simulation frame
- Lighting diagram or view
- Review slide
- Decision log

## Troubleshooting

- If a command or tool behaves differently, record the Blender version and compare the current Blender manual.
- If a modifier or bevel looks inconsistent, verify object scale before changing geometry.
- If an export looks wrong, re-import it into a clean file and compare dimensions, normals, hierarchy and materials.
- Never overwrite the preserved starter or baseline while diagnosing.
