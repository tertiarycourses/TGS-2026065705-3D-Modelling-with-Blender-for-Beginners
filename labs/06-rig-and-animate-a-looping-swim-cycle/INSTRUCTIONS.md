# Instructions — Lab 6

## Before you begin

- Use Blender and work only on a copy of the starter file.
- The supplied sample files originate from Blender 2.91. Open a copy in current Blender and use Save As before editing.
- Preserve the original input and save incremental versions.
- Capture evidence at the points named below.

## Step-by-step

1. Save a working copy and confirm mesh transforms.
2. Create and name a body-to-tail bone chain.
3. Check bone placement, parenting and bone roll.
4. Bind the mesh to the armature using suitable weights.
5. Pose the tail and fins at their expected extremes.
6. Repair weight leakage using Weight Paint and vertex groups.
7. Set the frame rate and intended cycle length.
8. Create body and tail key poses before in-between timing.
9. Offset fin and tail motion to create overlap.
10. Inspect interpolation and F-curves for overshoot.
11. Test the first and last frame for a seamless loop.
12. Capture rig, weights, curves and real-time playback evidence.

## Expected result

A rigged fish with a looped swim animation and deformation evidence.

## Evidence to include

- Armature hierarchy
- Weight-paint view
- Extreme-pose test
- F-curve view
- Loop playback or frame comparison

## Troubleshooting

- If a command or tool behaves differently, record the Blender version and compare the current Blender manual.
- If a modifier or bevel looks inconsistent, verify object scale before changing geometry.
- If an export looks wrong, re-import it into a clean file and compare dimensions, normals, hierarchy and materials.
- Never overwrite the preserved starter or baseline while diagnosing.
