# Lab 2: Interpret a fish brief, budget polygons and build a blockout

**Level:** Foundation

**Alignment:** K1–K2 · A1–A2

## Scenario

A client needs a recognisable goldfish prototype for a lightweight interactive scene.

## Objective

Translate the brief into criteria, allocate a polygon budget and create a modifier-led blockout.

## Output

A brief, scorecard and editable goldfish blockout within the stated budget.
