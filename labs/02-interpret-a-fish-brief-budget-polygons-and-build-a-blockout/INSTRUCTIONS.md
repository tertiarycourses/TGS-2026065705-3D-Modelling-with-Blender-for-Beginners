# Instructions — Lab 2

## Before you begin

- Use Blender and work only on a copy of the starter file.
- The supplied sample files originate from Blender 2.91. Open a copy in current Blender and use Save As before editing.
- Preserve the original input and save incremental versions.
- Capture evidence at the points named below.

## Step-by-step

1. Duplicate STARTER.blend and create a Brief text object or external note.
2. Record purpose, audience, viewing distance, dimensions, format and approver.
3. Define a 500-polygon target and clarify whether it refers to faces or triangles.
4. Allocate the budget across body, eyes, fins and tail.
5. Import or display side and top references where available.
6. Block the body with a low-resolution primitive and set dimensions.
7. Add eyes and fin planes using separate, named objects.
8. Use Mirror for bilateral parts and keep modifiers unapplied.
9. Check silhouette from side, top and perspective views.
10. Open viewport statistics and record the current count.
11. Remove or redirect geometry that does not support silhouette or deformation.
12. Capture the brief, budget, views and pass/fail decision.

## Expected result

A brief, scorecard and editable goldfish blockout within the stated budget.

## Evidence to include

- Creative brief
- Polygon allocation table
- Three key views
- Modifier stack
- Viewport statistics

## Troubleshooting

- If a command or tool behaves differently, record the Blender version and compare the current Blender manual.
- If a modifier or bevel looks inconsistent, verify object scale before changing geometry.
- If an export looks wrong, re-import it into a clean file and compare dimensions, normals, hierarchy and materials.
- Never overwrite the preserved starter or baseline while diagnosing.
