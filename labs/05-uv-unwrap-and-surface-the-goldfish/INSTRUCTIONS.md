# Instructions — Lab 5

## Before you begin

- Use Blender and work only on a copy of the starter file.
- The supplied sample files originate from Blender 2.91. Open a copy in current Blender and use Save As before editing.
- Preserve the original input and save incremental versions.
- Capture evidence at the points named below.

## Step-by-step

1. Open a copied starter and apply object scale if approved.
2. Mark seams along low-visibility regions and fin boundaries.
3. Unwrap the model and inspect island orientation and spacing.
4. Apply a checker texture and identify stretching.
5. Adjust seams or UVs until density is acceptably consistent.
6. Create a named material using Principled BSDF.
7. Connect base-colour texture data with the correct colour space.
8. Connect normal or roughness data as Non-Color where supplied.
9. Set plausible roughness and specular response for a wet fish surface.
10. Test the material under a neutral studio light.
11. Pack or place texture dependencies in the lab folder.
12. Capture UV, node and rendered evidence with version information.

## Expected result

A surfaced fish with validated UV layout, material channels and texture dependencies.

## Evidence to include

- UV layout
- Checker test
- Shader node graph
- Neutral render
- Dependency inventory

## Troubleshooting

- If a command or tool behaves differently, record the Blender version and compare the current Blender manual.
- If a modifier or bevel looks inconsistent, verify object scale before changing geometry.
- If an export looks wrong, re-import it into a clean file and compare dimensions, normals, hierarchy and materials.
- Never overwrite the preserved starter or baseline while diagnosing.
