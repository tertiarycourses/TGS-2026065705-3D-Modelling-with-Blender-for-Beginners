# Instructions — Lab 3

## Before you begin

- Use Blender and work only on a copy of the starter file.
- The supplied sample files originate from Blender 2.91. Open a copy in current Blender and use Save As before editing.
- Preserve the original input and save incremental versions.
- Capture evidence at the points named below.

## Step-by-step

1. Save the starter as a new working version and inspect symmetry.
2. Mark eye line, widest body, fin roots, mouth and tail landmarks.
3. Use Grab to establish the body, belly and tail arc.
4. Use Clay or Draw to add controlled secondary volume.
5. Use Smooth sparingly to remove noise without erasing landmarks.
6. Extrude or shape fins from simple, low-density geometry.
7. Add support loops only where silhouette or deformation needs them.
8. Inspect the model from front, side, top and perspective views.
9. Compare the current silhouette with the approved blockout.
10. Record polygon statistics and any Dyntopo or remesh decision.
11. Save a milestone before adding facial or surface detail.
12. Capture annotated before/after views and explain one modelling choice.

## Expected result

A recognisable goldfish model with intentional form, topology and saved milestones.

## Evidence to include

- Landmark view
- Sculpting before/after
- Wireframe view
- Polygon statistics
- Decision explanation

## Troubleshooting

- If a command or tool behaves differently, record the Blender version and compare the current Blender manual.
- If a modifier or bevel looks inconsistent, verify object scale before changing geometry.
- If an export looks wrong, re-import it into a clean file and compare dimensions, normals, hierarchy and materials.
- Never overwrite the preserved starter or baseline while diagnosing.
