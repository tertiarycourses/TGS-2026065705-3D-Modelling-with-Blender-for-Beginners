## Learner materials

- `courseware/` — visual course slides, Learner Guide and Lesson Plan
- `labs/` — eight connected, self-contained Blender labs with detailed instructions, checklists, sample `.blend` files and evidence presentations

The slide deck is concept-led. Detailed procedures appear only in the Learner Guide and lab packs.

## Course progression

1. Analyse the creative brief and establish a polygon budget.
2. Develop and refine a 3D model and prototype.
3. Rig, surface, animate and present the prototype.
4. Light, render, optimise, export and verify the asset.

## Requirements

- Blender 5.2 LTS or a compatible current Blender release
- A laptop capable of opening the supplied `.blend` sample files
- Presentation software for the evidence templates

Assessment instruments and answer keys are intentionally excluded from this public repository.
